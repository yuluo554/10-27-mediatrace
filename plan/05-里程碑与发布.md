## 四、本地等价校验现状（硬约束②）

> 命令一律写 `node tools/tasks.mjs <target>`（本机**没有 make**，实测 2026-10-27；
> `Makefile` 只是薄委托，`make x` 等价于 `node tools/tasks.mjs x`）。

| 项 | 本机可跑 | 证据 |
|---|---|---|
| 布局门 / 脱敏门 | ✅ | `node tools/tasks.mjs gates` 输出 PASS 行 + 扫描计数 |
| 两门的变异验证 | ✅ | `node tools/tasks.mjs verify-gates`（19 组全绿） |
| gitignore 三态（台账入库/样本不入库） | ✅ | `node tools/tasks.mjs check-ignore-rules`（含阳性对照实测） |
| `go build` / `go vet` / `go test` | ✅（Go 不在 PATH，tasks.mjs 自动探测） | `node tools/tasks.mjs test` |
| 交叉编译 | ✅ | `node tools/tasks.mjs cross`（linux/darwin/windows 三产物） |
| `--check` 双跑逐字节 | ✅（当前 3 例，C1–C3） | `node tools/tasks.mjs check-fixtures` |
| 冒烟（退出码） | ✅ | `node tools/tasks.mjs smoke` |
| **GitHub Actions** | ⬜ **未首推** | 写"CI 待首推验证"，**不得写"CI 绿"** |
