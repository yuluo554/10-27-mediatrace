## 一、公共契约

### 1.1 Finding（三态 + 证据四元组）

```go
type Status string // "pass" | "fail" | "gray"

type Finding struct {
    Module     string    // M1..M5
    RuleID     string    // 见各模块枚举
    Status     Status
    ByteOffset uint64    // fail 必填；gray 可缺省
    FieldPath  string    // 斜杠盒路径，索引从 0 起，按文件内顺序
    Values     []Value   // 各口径原值（整数 + 单位）
    Delta      *Delta    // fail 必填
    GrayReason string    // gray 必填，枚举闭集见 data/README §5.5
    Message    string    // 人读一句话，不含绝对路径
}
```

**渲染层拒绝**：`Status=="fail"` 且四元组任一为空 → 渲染函数返回 error（测试红），
不做"缺字段就省略"的宽容输出（`plan/01 §七.3`）。

### 1.2 模块接口

```go
type Module interface {
    ID() string                                  // "M1".."M5"
    Audit(input Input) ([]Finding, error)        // 纯函数：不含 I/O、不含时钟
}

type Input struct {
    Path  string        // 仅用于报告显示文件名（basename）
    Root  *isobmff.Box  // 已解析盒子树
    Raw   []byte        // 只读字节（用于取 stsd 子结构；大 mdat 不在此）
    Frags []isobmff.Fragment // moof/traf 解析结果（可为空）
}
```

- **`Audit` 幂等**：同 `Input` 两次调用 `reflect.DeepEqual` 相等。
- **`Audit` 无副作用**：不写 `Raw`，不读全局变量。
- 任一模块可单独运行：CLI 的 `--modules` 只决定"调用哪些 `Module`"。

### 1.3 排序与去重

- 排序键：`(Module, ByteOffset, FieldPath, RuleID)`。
- **同一根因合并**：`size` 异常导致的子盒越界只报 `truncated_parent` 一条，
  子盒不再逐条报（M1 纪律）。

## 二、M1 · 结构自洽

`internal/rules/structure` + `internal/isobmff`

| RuleID | 触发 | 证据 |
|---|---|---|
| `too_small_size` | 盒 `size` < 8（且非 0/1 形态） | 盒偏移 + 声明 size |
| `child_overruns_parent` | 子盒区间 ⊄ 父盒载荷区间 | 子盒偏移 + 父盒区间 |
| `duplicate_moov` | `moov` 出现 ≥2 次 | **列出全部**偏移 |
| `duplicate_mdat` | `mdat` 出现 ≥2 次（`plan/01 §五 M1` 要点 3） | 同上 |
| `stco_out_of_mdat` | `stco/co64` 偏移 + `stsz` 长度 ⊄ 任一 `mdat` 载荷 | 条目号 + 目标区间 vs mdat 区间 |
| `truncated_mdat` | 声明 size > 实际可读字节 | 声明 vs 实际 |
| `ftyp_brand_mismatch` | `ftyp` brand 与 `stsd` 样本条目不自洽 | brand 值 + 实际编码 |
| `max_depth_exceeded` | 遍历深度超限（防御） | 深度上限 |

**测试点**：C1/C2/C3 三例命中 3/3；深盒树（≥5000 层合成）不 panic 不爆栈；
`size==0` / `size==1` 两形态各自展开正确（golden 字节）。

## 三、M2 · 时长口径

`internal/rules/duration`

| RuleID | 触发 | 关键点 |
|---|---|---|
| `duration_mismatch` | 三口径互比超容差 | `values` 必须含三口径原值；`delta` 为最大差值 |
| `elst_item_rate_not_one` | `media_rate ≠ 1` | 报**条目号**；同段不按等速换算 |
| `elst_item_order_suspect` | 段次序使 `Σ` 与首帧 PTS 对不上 | 与"时长错"分开报（`plan/01 §八` 创新点） |
| `empty_edit` | `media_time == -1` | 报 `segment_duration` + 由此产生的起始偏移 |
| `first_pts_outside_media` | 首帧 PTS 不落在 `elst` media 区间 | 报 PTS 与区间 |
| `duration_unknown` (gray) | `mvhd.duration==0` 且推不出 | `reason=duration_unknown` |

**测试点**：GPAC `-edits` 造 3 段（含 `media_rate≠1`）逐条定位；S1 类 copy 前后差
（`elst` 而非 `stts`）；S7 类 2× 时长；`elst` 编号不排序（打乱顺序的样本要报条目号 1 而非 0）。

## 四、M3 · 时间戳

`internal/rules/timestamps`

| RuleID | 触发 | 关键点 |
|---|---|---|
| `dts_regression` | `dts[n] < dts[n-1]` | 报**样本序号** + `stts` 条目号 + 字节偏移；默认首个即止 |
| `tfdt_regression` | 跨分片 `tfdt` 回退 | 报分片序号 |
| `zero_duration_entry` | `stts.duration == 0` | 按 `data/README §5.4` 判 fail，不新增 gray |
| `dts_overflow_risk` | 累计越过字段位宽 | 报越界位置；`stts` 32 位 / `tfdt` v0/v1 分宽 |
| `timescale_suspect` (gray) | 极小 timescale | `reason=timescale_suspect` |
| `vfr_detected` (gray) | `stts` 条目 > 1 | `reason=vfr_detected` |

**测试点**：C5 命中并给样本序号；**≥20 正常 H.264/H.265（含 B 帧）误报 0**；
`ctts` v1 负偏移按有符号读（否则 B 帧误判，这条必须有专门单测）。
