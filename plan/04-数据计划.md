## 二、生成器契约

```
tools/fixture-gen/main.go
  --out <dir>          输出目录（默认 fixtures/out）
  --seed <uint64>      全部随机选择的唯一种子（默认固定常量）
  --suite <name>       all | defects | controls | m3-regression | m4 | m5
  --check              重生成到临时目录并与既有 manifest 逐字节比对
  --list               只打印 case 清单与 sha256
```

**纪律**：

1. **不读系统时间**（`time.Now` 在生成器内零引用，由 AST 测试守）。
2. **不读环境变量**参与字节生成。
3. **不调用 ffmpeg / MP4Box**：C1–C7 全部直接写盒子字节。理由（skill「真值的字节不能依赖
   工具链版本」）：ffmpeg 版本差异会改变 `moov` 字段排布，真值指纹随之漂移。
4. **`--check` 双跑**：生成到 `tmp1`、`tmp2`，断言两棵树逐字节相等，且与入库 `manifest.json` 相等。
5. 样本写完后**自算 sha256** 写进 manifest；`--check` 复算并比对。

## 三、真值纪律

| # | 纪律 | 落地 |
|---|---|---|
| T1 | **真值只存"输入参数 + 期望 finding 集合"**，期望值可由参数独立复算 | manifest 里不写"实现算出来的数"，只写构造参数与规则 ID |
| T2 | **真值的字节不依赖跑生成器那台机器的工具链** | 生成器零外部进程；同 seed 双跑逐字节一致（`node tools/tasks.mjs check-fixtures`） |
| T3 | **"没跑"不等于"通过"** | 真实样本登记表里未复跑的条目 `verified: null`，不进统计分母 |
| T4 | **计数类判据落不变量** | 不写"25 例"常量；断言 `len(cases) >= 25` 且 `C1..C7 每类 >= 1`（由集合算出） |
| T5 | **每条 fail 的四元组由构造点决定** | 生成器在 manifest 里记 `expected_offset`（构造时就知道写在哪一字节），实现必须匹配 |
| T6 | **对照组误报 0 是门禁** | `--suite controls` 全 pass 才算绿；任一 fail 即红 |
| T7 | **变异验证**：故意改坏一个期望，测试必须红 | `internal/rules/*/\*_test.go` 内的 mutation 子测试 |

## 六、真实样本登记格式

```json
{
  "samples": [
    {
      "id": "REAL-001",
      "filename": "sample-a.mp4",
      "sha256": "<64 hex>",
      "size_bytes": 0,
      "source_url": "https://<...>",
      "license": "<SPDX or text>",
      "verified": null,
      "note": "只读字节、不解码"
    }
  ]
}
```

- `verified: null` = **未复跑**（诚实标注，T3）。
- 未登记许可的样本**一律不用**（`data/README §3`）。
- 报告输出只写 `filename`，**不写绝对路径**。
